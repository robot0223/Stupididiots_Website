Drop Tap

A reaction-testing game with multiple modes, scoring, and a leaderboard.

About the project

Drop Tap explores a simple interaction: how quickly can you react? It brings game modes, scoring, and a leaderboard into a reaction-testing game that can be played, tested, and improved.

What it explores

Game modes
Multiple modes provide different ways to test a reaction.
Scoring
Scores give each round a result to compare.
Leaderboard
A leaderboard brings those results together.
